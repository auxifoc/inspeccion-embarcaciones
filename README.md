# Inspección técnica de embarcaciones de recreo — versión pública

Aplicación de campo del Trabajo Fin de Grado de Víctor Álvarez Albiol (Facultat de Nàutica de Barcelona, UPC). Este repositorio contiene **solo la aplicación construida**, generada automáticamente; el código fuente y la documentación están en el repositorio del trabajo.

La versión pública usa el guion del Anexo II del RD 1434/1999. No incluye el formulario de ninguna entidad de inspección ni manuales de fabricante. Los datos que se introducen se guardan solo en el dispositivo de quien la usa.

Dirección: https://auxifoc.github.io/inspeccion-embarcaciones/
